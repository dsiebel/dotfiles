# Logitech

## MX Master 3S

**Global Settings**

- Thumb Button: Gestures - Window Navigation
- Forward Button: Forward
- Back Button: Back
- Thumb Wheel: Horizontal Scroll
- Top Button: Middle Click
- Wheel Button: Shift wheel mode

**Visual Studio Code**

- Forward Button: Keyboard Shortcut `Ctrl + Shift + -`
- Back Button: Keyboard Shortcut `Ctrl + -`
